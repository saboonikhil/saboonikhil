#### [Kahwa](https://github.com/saboonikhil/kahwa)
*WhatsApp Web desk you host yourself*

Pair a session, work the inbox, then wire **workflows**: scheduled outbound, inbound replies, receipt acks. One tenant. No login wall. Runs on your machine.

**Stack:** TypeScript · Node.js · PostgreSQL · Prisma · whatsapp-web.js

```bash
git clone https://github.com/saboonikhil/kahwa.git && cd kahwa && npm install && npm run dev:local
```

[Repo](https://github.com/saboonikhil/kahwa) · [Issues](https://github.com/saboonikhil/kahwa/issues) · [License](https://github.com/saboonikhil/kahwa/blob/main/LICENSE)
